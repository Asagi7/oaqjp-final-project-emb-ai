Emotion Detection with IBM Watson NLP
Project Name: Emotion Detection Application using Watson NLP and Flask
This project detects emotions (anger, disgust, fear, joy, sadness) from text using IBM Watson NLP EmotionPredict model, wrapped in a Python Flask web application with unit tests and error handling.
Structure
EmotionDetection/emotion_detection.py - core Watson NLP function
EmotionDetection/init.py - package import
server.py - Flask deployment
test_emotion_detection.py - unit tests
templates/index.html - frontend
static/mywebscript.js - frontend script
